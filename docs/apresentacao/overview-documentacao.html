Como rodar o sistema

git clone https://github.com/viniciusbrito1/GeoProjeto_SIG.git
cd GeoProjeto_SIG
cp .env.example .env      # trocar as senhas
bash scripts/gerar_certificado_dev.sh
docker compose up -d --build

Acesso

https://localhost — sistema
https://localhost/api/docs — API

Testes

docker compose exec backend pytest -v

R03 · Evidências

Requisitos verificados à mão sem evidência podem ser reprovados na auditoria.
Resposta: uma evidência por indicador, nomeada pelo requisito.

16

R02 · Conhecimento concentrado

Só quem construiu o núcleo sabe explicá-lo.
Resposta: repasse do código; 2 pessoas demonstram o fluxo de empenho.

15

R01 · Instalação

Terceiro levar mais de 60 min para instalar (RNF-07).
Resposta: ensaio cronometrado com alguém de fora da equipe.
